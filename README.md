# INSIDE ARG Investigation Map

A single-page map of the INSIDE Collector's Edition ARG. Each puzzle gets a block; click one and you get the current state, what's been tried, what's still open, what to skip.

The point is to save new investigators from digging through nine years of Discord scrollback, scattered Reddit threads, dead Wayback snapshots and unindexed wikis just to figure out where one puzzle stands.

Concept by BigDusty on the Playdead Unofficial Discord, April 2026.
