# INSIDE ARG Investigation Map

A living map of every piece of the INSIDE Collector's Edition ARG, in one place.

Each part of the puzzle — the 108-cell sticker grid, the in-game printer, the terminal41.link archive, the breach hashes, the transmission, the dead-end paths people already tried — has a block on the map. Click a block to see what it is, what's been solved, what's still open, and which dead ends to skip. Arrows between blocks show how the pieces connect.

The map is meant to give a new investigator everything in one read. No more digging through nine years of Discord scrollback, scattered Reddit threads, dead Wayback snapshots and unindexed wikis to figure out the current state of a single puzzle.

Concept by BigDusty on the Playdead Unofficial Discord, April 2026.
